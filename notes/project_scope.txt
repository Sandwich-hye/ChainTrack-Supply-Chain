Project: ChainTrack Supply Chain Tracking System

Purpose:
Create a small blockchain-based prototype that records the movement of a product from the supplier to the retailer.

Main roles:
1. Admin
2. Supplier
3. Warehouse
4. Transport
5. Retailer

Main product flow:
1. Created
2. In Warehouse
3. Left Warehouse
4. In Transport
5. Arrived

Planned tools:
- Solidity
- Remix
- MetaMask
- Git
- GitHub

Main functions:
- Admin assigns user roles
- Supplier creates a product
- Warehouse records entry
- Warehouse records exit
- Transport updates shipping status
- Retailer confirms arrival
- Users search for a product and view its history

Initial limitations:
- This is a course prototype, not a commercial system
- No real cryptocurrency will be used
- No AWS, IPFS, Hyperledger or complex backend in the first version
- Blockchain records submitted information but cannot prove that real-world input is true
